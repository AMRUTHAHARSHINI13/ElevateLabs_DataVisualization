📌 Project Title

Sales Data Visualization and Business Insights using Power BI (Superstore Dataset)

🎯 Objective

The objective of this project is to analyze sales data using Power BI and create meaningful visualizations that help in understanding business performance and storytelling through data.

🛠 Tools Used
Microsoft Power BI Desktop
Superstore Dataset (CSV format)
📂 Dataset Description

The dataset used is the Superstore dataset, which contains sales information such as:

Sales
Profit
Discount
Category
Sub-Category
Region
Order Date
Customer Details

This dataset represents real-world retail business transactions.

📊 Steps Followed
1. Data Loading
The Superstore CSV file was imported into Power BI using Get Data → Text/CSV
Data was loaded successfully into Power BI model
2. Data Preparation
Verified column formats (Sales, Profit as numerical values)
Checked for missing or incorrect data
Ensured date field was properly recognized
3. Data Visualization Created
📌 KPI Card
Total Sales
📌 Profit by Category
Visual: Clustered Bar Chart
Insight: Compared profit across Furniture, Technology, and Office Supplies
📌 Sales by Region
Visual: Pie Chart
Insight: Identified best performing region
📌 Sales Trend Over Time
Visual: Line Chart
Insight: Showed sales performance over months/years
📌 Discount vs Profit
Visual: Scatter Plot
Insight: Showed relationship between discount and profit
📈 Key Insights (Storytelling)
Technology category generates the highest profit.
Furniture category shows lower profitability compared to others.
Western region has the highest sales contribution.
Higher discounts negatively affect profit margins.
Sales show fluctuations over time indicating seasonal trends.
🎨 Design Principles Followed
Used minimal and consistent colors
Avoided cluttered visuals
Maintained clear chart titles
Focused on business insights rather than only charts
📌 Outcome

This project helped in understanding:

How to clean and visualize data in Power BI
How to select correct charts for different types of data
How to extract meaningful business insights from raw data
Basics of data storytelling using dashboards
📎 Final Output
Interactive Power BI Dashboard
Visual charts representing sales insights
Business summary report
